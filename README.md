# Festival Waste Tracker

A web application built using ASP.NET MVC to manage and track festival waste efficiently.

## Features
- Waste tracking system
- Dashboard view
- MySQL database integration
- Clean UI using Bootstrap

## Tech Stack
- ASP.NET Core (.NET 8)
- C#
- MySQL
- Entity Framework Core

## How to Run
1. Download project
2. Open in Visual Studio
3. Setup database
4. Run project
